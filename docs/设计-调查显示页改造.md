# 设计：调查显示页改造（第二轮）

> 范围：User 端调查页面全面重构。替换原"项目列表→小班列表→网格/详情"三级跳转为单页级联调查。

## 一、现状问题

| 问题 | 原因 |
|---|---|
| `gridProjectNameFilter` 和 `gridProjectFilter` 两个下拉重复 | 新上传逻辑下一个项目=一个 project_name，项目名称层冗余 |
| `gridTabs`（表1~5 tab）多余 | 分类选择已隐含表选择（人工造林=table1...草原=table5） |
| 首页是项目列表，需多次点击才能调查 | 调查页应首页直达 |
| 网格是"所有小班横排"，不利于单小班聚焦 | 改为选定小班后两列表格（label|值） |
| 样方无处编辑 | 默认所有分类切换样方模式，表头+多行（先简单，无定义用最小模板） |

## 三、级联筛选规则

```
项目（gridProjectFilter，保留）
  ↓ 项目含有的分类（从 subcompartment_rows.category 去重）
分类（gridCategoryFilter，新增，替代 gridTabs + gridProjectNameFilter）
  ↓ 该项目+分类下的小班
县/乡/村/林班/小班（gridTownshipFilter...，保留级联）
```

- **项目**：`GET /api/projects` → 所有项目
- **分类**：选定项目后，从 `subcompartment_rows` 的 `category` 字段去重得到该项目的分类清单
- **县/乡/村/林班**：选定项目+分类后级联，仅展示该范围内的可用值
- **小班**：最终选定一个小班

不同分类下小班可能重复（同一个小班在多个分类图层出现），按分类独立过滤。

## 四、调查表两种模式

### 4.1 默认模式（小班一对一，两列 label|值）

选定小班后，按当前分类对应的表（如选"人工造林"→table1）渲染调查表：
- **左列**：字段 label（黄色背景=预填只读，白色=录入）
- **右列**：字段值（黄色行=小班属性预填不可编辑，白色行=可编辑录入）
- 每个字段一行，垂直排列
- 编辑后失焦自动保存（PUT `survey/<table_id>/rows`）

### 4.2 样方模式（默认所有分类都有，一对多）

点击"切换样方"按钮后，渲染样方表：
- **第一行表头**：样方字段 label（样方编号/经度/纬度/...）
- **后续每行一个样方**：可增删
- 保存到 `data_json.samples` 子数组
- 切回默认模式：样方数据保留，不丢失

**样方字段按分类定义**：默认所有分类都显示"切换样方"按钮（先简单）。schema 中表有 `sample_array` 字段且有 `sample_fields` 定义时，按定义的字段渲染；无定义时用最小默认模板（样方编号+备注）。后续按分类补充字段/模板，没有定义的字段不显示。

## 五、按钮显示规则

| 按钮 | 显示条件 |
|---|---|
| 导出 | 选定项目后（顶栏） |
| 照片/轨迹/打卡 | 选定小班后 |
| 切换样方 | 选定小班后（默认所有分类都有，先简单） |
| 保存 | 默认模式失焦自动保存；样方模式点保存按钮 |

## 六、代码改动点

### 6.1 state 新增/修改

```javascript
// 新增
gridCategory: '',     // 当前分类（人工造林/.../草原）

// 删除
gridProjectName,      // 项目名称层去掉
// gridTable 由 gridCategory 推导（分类→表映射），不再独立存
```

### 6.2 分类→表映射（前端）

```javascript
const CATEGORY_TO_TABLE = {
  '人工造林': 'table1',
  '封山育林': 'table2',
  '退化林修复': 'table3',
  '水利水保': 'table4',
  '草原': 'table5',
};
// 选分类 = 选表，gridTable = CATEGORY_TO_TABLE[gridCategory]
```

### 6.3 首页默认

```javascript
// init() 中
state.view = 'survey_grid';  // 原 'projects' 改为调查页
```

### 6.4 工具栏重构

去掉 `gridProjectNameFilter`、`gridTabs`，新增 `gridCategoryFilter`：
```
项目 → 分类 → 县 → 乡 → 村 → 林班 → 小班
```

### 6.5 调查表渲染

替换原"所有小班横排网格"为"选定小班的两列表格"：
- 默认模式：`renderSurveyForm()` — jspreadsheet 两列（label|值）
- 样方模式：`renderSampleGrid()` — jspreadsheet 多列（表头+样方行）

### 6.6 后端

- `GET /api/projects/<pid>/subcompartments?category=X` 已支持，无需改
- 新增 `GET /api/projects/<pid>/categories` → 返回该项目含有的分类清单

## 七、实施顺序

1. 后端：新增 `/api/projects/<pid>/categories` 端点
2. app.js state：新增 gridCategory，删 gridProjectName
3. app.js init：首页默认 view='survey_grid'
4. app.js 工具栏：去 gridProjectNameFilter/gridTabs，加 gridCategoryFilter
5. app.js 调查表：默认模式两列 label|值 + 样方模式表头多行
6. app.js 按钮：照片/轨迹/打卡/导出/样方切换 显示规则
7. 验证：级联筛选 + 两列编辑保存 + 样方增删 + 导出
